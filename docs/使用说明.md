# MagTc 2 使用说明（简要）

MagTc 2 计算二维和三维磁体的居里温度或奈尔温度。完整流程分四步：

1. 由 VASP 能量映射得到交换常数 J 和单离子各向异性 K；
2. 用 `ground` 判断共线基态；
3. 做蒙特卡罗模拟；
4. 由 chi_abs 峰值给出 T_C 及误差。

内核按 JCP 2026 单层 VN 论文的协议运行，默认设置下与 `kernels/tc_jcp_rect.py` 逐位一致。

## 约定

经典单位矢量自旋，能量单位 meV，J > 0 为铁磁，每对自旋只计一次：

    H = − Σ_<ij> [ Jxy (Sx Sx' + Sy Sy') + Jz Sz Sz' ] + Σ_i Σ_a K_a (S_i^a)^2

若文献使用 |S| = S 并带 1/2 重复计数因子，填入模型文件前需换算为每对的 J·S²。`magtc dft` 用单位自旋做映射，拟合出的 J 已经是这种约定，无需再换算。

## 安装

    pip install -e ".[fast]"

安装后包含 numpy、pyyaml、numba。没有 numba 也能运行，但只适合测试。

## 从 VASP 到 T_C

    magtc dft setup POSCAR --magnetic Cr --nshell 3 --supercell 2 2 --template vasp_template/ --outdir map
    # 在 map/ 下各子目录里运行 VASP
    magtc dft collect map --out model.yaml
    magtc ground model.yaml
    magtc batch model.yaml --nproc 8 --overrelax 2 --wolff 10
    magtc analyse magtc_out/*_seed*.json --plot tc.png

- `vasp_template/` 中放入你自己的 INCAR（泛函、U、ENCUT、展宽等）、KPOINTS 和 POTCAR。程序只改写 ISPIN、MAGMOM 和 LSORBIT/LNONCOLLINEAR，并把自动 k 网格按超胞倍数缩小。
- `setup` 生成两类计算：
  - 共线磁构型，用于拟合 J。构型按 D-最优准则选取，使拟合条件数尽量小。
  - 三个带自旋轨道耦合的计算，铁磁矩分别沿 x、y、z，用于求 K。
- `collect` 的工作：
  - 读取 E0（`--energy F` 改读自由能）；
  - 检查 OUTCAR 中的局域磁矩是否翻转或塌缩；
  - 最小二乘拟合 J，并给出标准误差、留一残差和条件数；
  - 写出模型文件：MC 序参量自动设为共线基态，并按平均场 T_C 给出一个粗扫温度区间。
- 方法与维度：
  - `--method fourstate` 改用四态法，要求超胞足够大，使每对自旋只由一条键相连。
  - `--dim 3` 用于三维体材料。

## 蒙特卡罗设置

| 项目 | 默认（JCP 协议） | 可选 |
|---|---|---|
| 协议 | anneal：温度从高到低，构型逐温度传递 | pt：并行回火 |
| 每步移动 | 均匀新方向 Metropolis | cone 自适应步长；overrelax 过弛豫；wolff 团簇 |
| 每个温度的步数 | 1e5 热化 + 2e5 测量，每 20 步测量一次 | 任意 |
| 种子数 | 8 | 任意 |

快速算法对 XXZ 和单离子各向异性都是严格的：过弛豫只改变各向异性能，这部分用 Metropolis 判定接受；Wolff 团簇中，XXZ 和 K 的剩余能量对整个团簇做一次 Metropolis 判定。

VN 在 L = 50、425 K 下，以每个独立 |M| 样本的耗时计：Metropolis + 2 次过弛豫比纯 Metropolis 快约 17 倍，加 20 个 Wolff 团簇约快 50 倍。可以用 `magtc bench model.yaml --T 温度` 为自己的体系挑选移动组合。

每次运行都会记录：|M| 和 E 的积分自相关时间、接受率、团簇大小，以及并行回火的交换接受率。`analyse` 会在独立样本过少或峰位落在温度端点时给出警告。

## 模型文件要点

- `structure`：维度 `dim`（2 或 3）、晶格矢量（Å）、磁性位点的分数坐标。
- `interactions`：
  - `shell: n` 自动取第 n 个距离壳层的全部键；
  - 也可以写显式键 `[s1, s2, da, db, dc]`，每对只写一次；
  - 各向同性写 `J`，XXZ 写 `Jxy` 和 `Jz`。
- `anisotropy.K`：`[Kx, Ky, Kz]`，也可以按子格分别给出。
- `orders`：`q`（每个分量取 0 或 1）加上每个子格的符号；FM 已预定义。
- `mc`：未写出的项一律取 JCP 默认值。

1.x 格式的模型文件仍可直接读取。

## 局限

- 只支持共线能量映射和 Heisenberg/XXZ 交换，不含 DMI、Kitaev 或双二次交换。
- `ground` 只检查共线态，不能发现螺旋态。
- 不做有限尺寸外推，也不做量子修正。
- DFT 接口目前只支持 VASP。

注意：未发表的参数（例如 CrN₂、MnN₂ 的 J、K）不要提交到本公开仓库，请在本地单独存放模型文件。
