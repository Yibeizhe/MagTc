# MagTc 使用说明（简要）

MagTc 是二维磁体经典蒙特卡罗 T_C 计算的统一入口。其内核与 JCP 2026 单层 VN 论文
（`vn_tc_batch_L50_prod.py` 和 `kernels/tc_jcp_rect.py`）的算法完全相同：矩形晶格下，同一随机种子的结果逐位一致。

## 约定

经典单位矢量自旋，能量单位 meV，J > 0 为铁磁，每对只计一次：

    H = − Σ_<ij> [ Jxy (Sx Sx' + Sy Sy') + Jz Sz Sz' ] + Σ_i Σ_a K_a (S_i^a)^2

易轴 z 可写作 K = (D, D, 0) 或 K = (0, 0, −D)。若文献使用 |S| = 3/2 并带 1/2 重复计数因子，需先换算成每对的 J·S²，再填入模型文件。

## 安装

    pip install -e ".[fast]"      # numpy、pyyaml、numba

没有 numba 也能运行（纯 Python，速度很慢，只适合测试）。两种后端的随机数序列不同，结果不能混合分析，`analyse` 会拒绝混合输入。

## 常用命令

    magtc show    model.yaml                 # 查看规范化后的模型、温度序列和种子
    magtc ground  model.yaml                 # 共线候选序的零温能量，检查基态
    magtc run     model.yaml --seed-index 0 --outdir runs
    magtc analyse runs/*.json --out res.json --plot res.png
    magtc batch   model.yaml --nproc 8 --outdir runs          # 本机多进程跑完所有种子并分析
    magtc batch   model.yaml --pbs job.pbs --queue batch      # 只生成 PBS 阵列脚本，不提交

蒙特卡罗参数可在命令行覆盖，例如 `--L 24 --ntherm 20000 --nmeas 40000 --Tmax 450 --Tmin 390`。

## 默认协议（JCP 2026）

L = 50，单自旋 Metropolis（新方向在球面上均匀抽取），温度从高到低扫描。每个温度 1e5 步热化、2e5 步测量，每 20 步测量一次，8 个独立种子。T_C 取全矢量序参量 chi_abs 峰值，用三点抛物线插值确定；误差取留一种子 jackknife 与单种子峰位 SEM 中的较大者。同时给出 C_v 峰作为参考，不做有限尺寸外推。若峰位落在温度序列端点，结果会标注 `PEAK AT EDGE`，需要扩大扫描窗口。

## 模型文件要点

- `lattice.type`：`square`、`rectangular`、`honeycomb`（两个子格）或 `custom`（自定义 `sublattices`）。
- `exchange`：按壳层列出键 `[from_sub, to_sub, da, db]`，每对只写一次。各向同性写 `J`；XXZ 写 `Jxy` 和 `Jz`。
- `anisotropy.K`：`[Kx, Ky, Kz]`，也可以每个子格各给一组。
- `order_parameters`：`q: [qa, qb]`（0 或 1）加上每个子格的符号 `signs`。单子格默认提供 FM、stripe_a、stripe_b、Neel。
- `order`：蒙特卡罗测量所用的序参量。应先用 `ground` 确认它是能量最低的共线态。
- `mc`：未写出的项一律取 JCP 默认值。

示例见 `examples/`：VN（`vn_b2p7342.yaml`）、CrI₃（`cri3_lado2017.yaml`，使用前请先核对文件头所列参数）、Ising 基准（`ising_square.yaml`）。

## 测试与验证

    pytest -m "not slow"                          # 快速回归测试（CI）
    python validation/validate_vn.py --reduced    # VN b = 2.7342 Å，L = 50，缩减步数

完整协议下，VN 的预期结果为 420 ± 2 K（JCP 值 419.7 K）。

注意：未发表的参数（例如 CrN₂、MnN₂ 的 J、K）不要提交到本公开仓库，请在本地单独存放模型文件。
